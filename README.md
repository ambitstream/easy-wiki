# Easywiki
Easywiki is an experimental web application that summarizes Wikipedia articles using ChatGPT.
It was my first hands-on project with the OpenAI API, built shortly after the API’s initial release, as an exploration of AI-driven summarization and early LLM integration in web applications.

The application uses the Wikipedia API to search for articles. As the user types into the search bar, matching article titles are fetched and displayed in a dropdown list (similar to Google search suggestions). After selecting an article, the app shows a short AI-generated summary and provides a link to the full Wikipedia page, opened in a new window.
